# Print bootstrap intervals for a Markov chain

Print bootstrap intervals for a Markov chain

## Usage

``` r
# S3 method for class 'markovchainBootstrap'
print(x, digits = 4, ...)
```

## Arguments

- x:

  A `"markovchainBootstrap"` object returned by
  [`bootstrapProperties`](bootstrapProperties.md).

- digits:

  Number of significant digits.

- ...:

  Passed to `print`.

## Value

`x`, invisibly.
