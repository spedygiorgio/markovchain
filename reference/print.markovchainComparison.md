# Print a comparison of two Markov chains

Print a comparison of two Markov chains

## Usage

``` r
# S3 method for class 'markovchainComparison'
print(x, digits = 4, ...)
```

## Arguments

- x:

  A `"markovchainComparison"` object returned by
  [`compareChains`](compareChains.md).

- digits:

  Number of significant digits.

- ...:

  Passed to `print`.

## Value

`x`, invisibly.
