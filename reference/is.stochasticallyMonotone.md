# Check if a Markov chain is stochastically monotone

Verifies if the transition matrix of the Markov chain is stochastically
monotone.

## Usage

``` r
is.stochasticallyMonotone(object)

# S4 method for class 'markovchain'
is.stochasticallyMonotone(object)

# S4 method for class 'matrix'
is.stochasticallyMonotone(object)

# S4 method for class 'ANY'
is.stochasticallyMonotone(object)
```

## Arguments

- object:

  A markovchain object or a transition matrix.

## Value

A boolean value.
